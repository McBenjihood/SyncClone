### Recommended Reading & Learning Resources

#### 1. Official Documentation & Guides
* **Java NIO File API (The Official Java Tutorial):**
    * *Resource:* [Oracle Java Tutorials: File I/O (Featuring NIO.2)](https://docs.oracle.com/javase/tutorial/essential/io/fileio.html)
    * *Focus on:* The chapters on **Path Operations** and **Creating and Reading Files**.
* **Java Concurrency:**
    * *Resource:* [Jenkov Concurrency Tutorial - ConcurrentHashMap](https://jenkov.com/tutorials/java-util-concurrent/concurrenthashmap.html)
    * *Why:* Great visual breakdown of how `ConcurrentHashMap` works and its thread guarantees.

#### 2. Jackson (JSON) Tutorials
* **Baeldung's Jackson Series:**
    * *Article:* [Jackson – Save JSON to a File](https://www.baeldung.com/jackson-save-json-to-file)
    * *Article:* [Jackson with Java Records](https://www.baeldung.com/java-record-jackson)
    * *Article:* [Jackson – Java 8 Date/Time (JSR-310)](https://www.baeldung.com/jackson-java-8-date-handling)

#### 3. Atomic File Writes
* **Baeldung: File Move Operations in Java:**
    * *Article:* [Java – Moving Files with NIO](https://www.baeldung.com/java-move-files)
    * *Note:* Pay special attention to how `StandardCopyOption.ATOMIC_MOVE` behaves.
